03 / 04 PY · TS

QuMail

Email with a quantum-secure dial — pick your own paranoia level.

A desktop email client that treats encryption as a sliding scale instead of a single switch: an information-theoretically secure one-time pad for the most sensitive messages, QKD-derived AES-256-GCM for everyday secure mail, post-quantum Kyber + Dilithium for messages that need to stay safe decades from now, and a plain fallback for compatibility. A simulated key manager speaks the real ETSI GS QKD 014 protocol, so the security layer can be swapped for actual QKD hardware later.

04 / 04 GO

RadixKV

Stop paying to re-think the same prompt prefix.

When hundreds of agent branches share the same system prompt, most LLM caches still re-process those identical tokens on every single call. RadixKV fixes that with a concurrent radix tree that lets thousands of branches share memory for common prefixes — lock-coupled for safe concurrent mutation — paired with an O(1) min-heap eviction policy that prunes dead conversation leaves while keeping shared trunks intact.
